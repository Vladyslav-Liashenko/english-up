# EnglishUp: Telegram Mini App для вивчення англійської

Один Cloudflare Worker роздає фронтенд (папка `public`) і API для ІІ. Прогрес користувача зберігається в Telegram CloudStorage (дублюється в localStorage), власна БД не потрібна.

## Що всередині

| Розділ | Що є |
|---|---|
| Профіль | Фото й ім'я з Telegram, рівень CEFR A1–C2 (наступний відкривається після всіх уроків рівня та іспиту ≥70%), ігровий рівень за XP, серія днів, статистика, досягнення |
| Геймифікація | 3 щоденні завдання (+20 XP кожне, скриня +50 XP за всі три), план на тиждень (+100 XP), 12 досягнень |
| Напрям | Загальна, IT, Подорожі, Бізнес (обирається при старті та в налаштуваннях) |
| Курс | 6 рівнів × 4 уроки. Урок: 10–15 нових слів (🔊, + у словник), правило, вибір перекладу, пропуски, переклад речень. Слова, яких немає в статиці, генерує ІІ і кешує |
| Граматика | 13 тем (усі часи + going to), правило й практика по кожній |
| Часи | Шпаргалка-таблиця 3×4, по тапу: формули + − ?, коли вживати, маркери, приклади |
| Словник | Мої слова (+ додати будь-яке слово, ІІ підтягне транскрипцію й переклад), картки, ✓ = вивчено (слово покидає словник) |
| Неправильні дієслова | 100 дієслів, пошук, озвучка, тренування V2/V3 |
| Практика | Переклад EN ⇄ UK/RU (перевіряє ІІ), пропущені слова, есе з оцінкою й розбором помилок, голосова розмова за сценаріями (робота, співбесіда, стендап, аеропорт…), питання з граматики |
| Налаштування | Мова (UK/RU), напрям, рівень, швидкість озвучки, автоозвучка, скидання прогресу |

Озвучка: `speechSynthesis` браузера; якщо у WebView немає англійського голосу, звук синтезує Workers AI (MeloTTS).
Розпізнавання мови: запис з мікрофона → Workers AI Whisper.
ІІ-функції: Claude API (`claude-haiku-4-5` за замовчуванням, змінюється у `MODEL`).

## Деплой (≈10 хвилин)

1. **Бот**: у @BotFather виконай `/newbot`, збережи токен.
2. **Ключ Claude**: створи на console.anthropic.com → API Keys.
3. **Встановлення**:
   ```bash
   npm install
   npx wrangler login
   npx wrangler secret put ANTHROPIC_API_KEY
   npx wrangler secret put BOT_TOKEN
   npx wrangler secret put WEBHOOK_SECRET    # будь-який рядок, напр. 32 випадкові символи (A-Z a-z 0-9 _ -)
   npx wrangler deploy
   ```
4. Візьми URL з виводу (`https://english-up.<subdomain>.workers.dev`), встав у `wrangler.toml` → `APP_URL` (з `/` у кінці) і виконай `npx wrangler deploy` ще раз.
5. Відкрий у браузері `https://english-up.<subdomain>.workers.dev/setup?key=<WEBHOOK_SECRET>`: буде зареєстрований webhook, кнопка меню й команда /start.
6. (Опційно) У @BotFather: `/newapp`, щоб отримати пряме посилання на кшталт `t.me/<bot>/app`.
7. (Опційно) Денний ліміт ІІ-запитів на користувача: `npx wrangler kv namespace create LIMITS`, потім розкоментуй блок `kv_namespaces` у `wrangler.toml` і встав id.

Workers AI (голос) вмикається автоматично через `[ai]` у `wrangler.toml`. Безкоштовного денного ліміту Cloudflare вистачає для тестів.

## Локальна розробка

```bash
echo 'DEV_MODE="1"' > .dev.vars   # дозволяє API без підпису Telegram
npx wrangler dev
```
Відкрий http://localhost:8787. Без Telegram прогрес зберігається в localStorage.
На проді `DEV_MODE` має бути `"0"`: кожен запит перевіряється підписом `initData` від Telegram.

## Структура

```
public/
  index.html, styles.css
  js/core.js     стан, збереження, XP/завдання/досягнення, озвучка, запис голосу, API
  js/app.js      екрани та навігація
  js/i18n.js     тексти UK/RU
  data/          часи, речення для вправ, неправильні дієслова, слова уроків
worker/index.js  API (/api/ai, /api/stt, /api/tts), бот (/webhook), /setup
wrangler.toml
```

## Як додати контент

- Слова уроку: `public/data/words.js`, блок `# <напрям>_<рівень>_<номер> Назва`, далі рядки `слово|транскрипція|укр|рус`. Статичні слова мають пріоритет над згенерованими ІІ.
- Речення для вправ: `public/data/sentences.js`, формат `час|речення з [відповіддю]|підказка|укр|рус`.
- Дієслова: `public/data/verbs.js`.
